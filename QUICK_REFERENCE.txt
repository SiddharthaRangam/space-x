## 🚀 Common Tasks

### To Add a New Page
1. Create file in `src/components/pages/NewPage.jsx`
2. Add route to `src/components/App.jsx`
3. Import in App.jsx: `import NewPage from './pages/NewPage'`

### To Add a New Hook
1. Create file in `src/hooks/useNewHook.js`
2. Export function: `export const useNewHook = () => {...}`
3. Import where needed: `import { useNewHook } from '../hooks/useNewHook'`

### To Add a New Constant
1. Open `src/config/constants.js`
2. Add new constant
3. Export it: `export const NEW_CONST = {...}`
4. Import where needed: `import { NEW_CONST } from '../config/constants'`

### To Add a New Style
1. Add to `src/styles/index.css`
2. Use in components

## 🎯 Import Cheat Sheet

```javascript
// From src/main.jsx (at root)
import App from './components/App'
import './styles/index.css'

// From src/components/App.jsx
import Layout from './layout/Layout'
import Home from './pages/Home'

// From src/components/pages/Home.jsx
import { BUTTON_STYLES } from '../../config/constants'

// From src/components/layout/NavBar.jsx
import { useCountdown } from '../../hooks/useCountdown'
import { NAV_MENU_ITEMS } from '../../config/constants'
```

## ✅ Folder Purposes

```
📁 components/     → React UI Components
   📁 layout/      → Components that wrap pages
   📁 pages/       → Full page components (one per route)

📁 config/         → Application configuration & constants

📁 hooks/          → Custom React hooks

📁 styles/         → Global CSS and Tailwind imports

📁 public/         → Static files (fonts, images)
```
